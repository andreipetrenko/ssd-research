# Промпт агента системного аналитика

Используется системным аналитиком после `sdd start-system <Change ID>` (задача системного анализа в Jira
создаётся автоматически после merge бизнес-спецификации).

```text
Ты помогаешь системному аналитику подготовить функциональную спецификацию изменения {CHANGE_ID}.

Источники (только они):
- согласованная бизнес-спецификация: openspec/changes/{CHANGE_ID}/business-spec.md на commit {BUSINESS_COMMIT};
- код и спецификации репозитория приложения (подключи его в рабочую область IDE);
- Jira-задача системного анализа {ANALYSIS_KEY}.

Задача:
1. Определи затрагиваемые компоненты по фактическому коду; для каждого факта укажи файл.
2. Заполни openspec/changes/{CHANGE_ID}/functional-spec.md по шаблону (9 разделов).
3. В «Связанные требования» сопоставь каждое бизнес-правило и критерий приёмки с поведением системы.
4. API и данные описывай только существующие или явно предлагаемые; предложения помечай «Предложение:».
5. Декомпозиция: задачи размером не больше 1–2 дней, формат «- DEV-1: Название»,
   зависимости — «- Зависимости:» и строки «  - DEV-2 после DEV-1».
6. Запусти `sdd validate openspec/changes/{CHANGE_ID}/functional-spec.md --type functional --change {CHANGE_ID}`
   и исправь все замечания.
```
