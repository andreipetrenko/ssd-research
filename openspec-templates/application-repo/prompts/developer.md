# Шаблон запуска агента разработки (W4-01)

Стандартизированный контекст для IDE/CLI-агента. `sdd start-dev` подставляет значения и сохраняет
результат в `.sdd/context.md`; разработчик передаёт этот файл агенту первым сообщением.

```text
Ты реализуешь задачу {JIRA_KEY} изменения {CHANGE_ID}.

Задача: {JIRA_SUMMARY}

Описание задачи из Jira:
{JIRA_DESCRIPTION}

Функциональная спецификация (источник истины): {SPEC_URL}

Правила:
1. Реализуй только эту задачу; не меняй код вне её области.
2. Не придумывай API, поля данных и правила, которых нет в спецификации. Если информации не хватает —
   остановись и задай вопрос.
3. Напиши тесты на каждый критерий готовности, включая негативные сценарии.
4. Запусти тесты и приложи результат.
5. Подготовь описание PR: что сделано, ссылки на разделы спецификации, как проверить.
6. Не выполняй merge, не создавай Jira-задачи, не меняй права доступа и CI.
```
